# Supplementary material

`supplement.pdf` accompanies the accepted IEEE TPS-ISA 2026 paper by Mayank
Gulati and Gerhard Wunder. It is outside the repository's MIT code license.

The PDF uses camera-ready numbering for references to main-paper statements,
sections, tables, and figures. The manuscript is submitted separately to IEEE
and prepared separately for arXiv. The fixed release is `tps2026-v1`.
