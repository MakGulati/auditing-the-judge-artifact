# Anonymous-release checklist

- Fresh Git history only; no commits were copied from the private repository.
- Repository-local Git identity is `Anonymous Authors <anonymous@invalid.example>`.
- No private remote is configured.
- No names, institutional email addresses, personal GitHub handles, or absolute
  workstation paths are present in tracked text files.
- No credentials, editor settings, agent settings, environments, raw logs, or model
  caches are included.
- Artifact metadata retains scientific provenance (model IDs, hashes, seeds,
  package versions, and relative source paths) without personal provenance.

Before publishing, use an account or archival service whose owner profile, URL,
commit-signing configuration, email privacy settings, and organization membership
do not reveal author identity. Do not fork the private repository: forking exposes
repository relationships and preserves history.
